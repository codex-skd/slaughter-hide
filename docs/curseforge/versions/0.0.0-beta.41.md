<h2>v0.0.0-beta.41 - Butcher decoration blocks</h2>

<p>Adds the decorative furniture families from the original mod that hadn't been ported yet.</p>

<h3>Add</h3>

<ul>
<li><strong>41 decoration blocks</strong>: 8 wooden counters, 15 coloured canopies, 10 butcher's tables (9 woods + metal) and 8 butcher displays.</li>
<li>All craftable from vanilla materials, all drop themselves, all in the Blocks creative tab, fully translated (EN + ES).</li>
</ul>

<p>These are plain decorative blocks &mdash; the original had a vestigial container on the tables and displays; that isn't ported.</p>
