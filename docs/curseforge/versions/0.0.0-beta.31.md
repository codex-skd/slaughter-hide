<h2>v0.0.0-beta.31 - 30 new mechanical/decorative blocks</h2>

<p>Adds 30 blocks from the original Butchery catalog that aren't part of the carcass-butchering system: ore/decoration blocks, storage barrels, trophy mounts, cooked/raw sausage decorations, and a handful of blocks with real gameplay logic.</p>

<h3>Add</h3>
<ul>
<li><strong>26 simple blocks</strong>: <code>deepslate_sulfur_ore</code>, <code>sulfur_ore</code>, the diorite brick family (<code>diorite_bricks</code>, <code>_slab</code>, <code>_stairs</code>, <code>_wall</code>), the salt formation set (<code>base</code>/<code>middle</code>/<code>frustum</code>/<code>tip</code>), <code>salt_block</code>, <code>dragon_scale_block</code>, <code>bone_barrel</code>, <code>cod_barrel</code>, <code>salmon_barrel</code>, <code>floorstanding_sign</code>, <code>butcher_statue</code>, <code>cling_film</code>, <code>photos</code>, <code>ravager_head</code>, <code>ravager_head_mount</code>, <code>iron_golem_head_mount</code>, <code>cooked_blood_sausages</code>, <code>cooked_sausages</code>, <code>raw_blood_sausages</code>, <code>raw_sausages</code>.</li>
<li><strong>4 blocks with real logic</strong>: <code>blood_splatter</code> (right-click with an empty hand to progressively wipe it clean, 10 stages), <code>plastic_sheet</code> / <code>plastic_sheet_corner</code> (auto-updates its sealed/open visual state based on the block above it), <code>spike_trap</code> (deals damage and applies Mining Fatigue to anything that steps on it).</li>
</ul>

<h3>Fix</h3>
<ul>
<li>Two carcass definitions (<code>medium_magma_cube</code>, <code>small_magma_cube</code>) were built but never actually registered, making their items unreachable in-game.</li>
<li>Missing <code>iron_hacksaw</code>/<code>iron_hammer</code> item textures (showed as missing-texture purple/black in-game).</li>
<li>Startup crash: <code>diorite_brick_stairs</code> was registered before <code>diorite_bricks</code>, the block it depends on, causing a registry rollback that also broke unrelated already-working blocks.</li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>4 special mobs</strong> (Enderman 8 cuts, Strider 3 cuts, Sniffer 3 cuts + fur + head, Turtle 7 cuts)</li>
<li><strong>84/79 mobs</strong> ported</li>
</ul>

<p><em>Tool tier textures (copper/gold/diamond/netherite/bone) are still placeholders reusing the iron texture. Visible blood pooling and the remaining ~16 workstation-style blocks (Basin, Freezer, Meat Grinder, Skinning Rack, Taxidermy Table, etc.) are not in this release yet.</em></p>
