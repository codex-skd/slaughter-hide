<h2>v0.0.0-beta.2 - First playable slice: the cow</h2>

<p>First functional beta of the Butchery port. This release implements the full butchering loop end-to-end for a single reference mob (the cow), built on a generic system designed to scale to the rest of the original mod's mobs without one-off code per animal.</p>

<h3>Add</h3>
<ul>
<li><strong>Full cow butchering loop</strong>: kill a cow to get a hanging carcass, bleed it with a cleaver, wait for it to drain (or enable instant draining in the config), then cut it up in sequence — head, skin, and three meat cuts — until the carcass is gone.</li>
<li><strong>Iron cleaver</strong> and <strong>Iron skinning knife</strong>, the two tools needed for the loop.</li>
<li><code>INSTANT_BLEED</code> config option (<code>SlaughterHide.toml</code>) to skip the real-time bleed-out delay for testing.</li>
</ul>

<h3>Fix</h3>
<ul>
<li>Startup crash caused by resolving block references before block registration completed.</li>
</ul>

<h3>Known issues</h3>
<ul>
<li>The mounted cow head trophy block (<code>cow_head_mount</code>) fails to render — its model is inherited unchanged from the original Butchery mod and NeoForge 26.2's stricter model validation now rejects it. Does not affect the butchering loop. Will be fixed in a follow-up release.</li>
</ul>

<blockquote>This is an early, narrow-scope beta covering only the cow. It is meant for testing the core mechanic before the rest of the original mod's mobs are ported.</blockquote>
