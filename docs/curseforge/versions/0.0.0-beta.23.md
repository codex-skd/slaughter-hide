<h2>v0.0.0-beta.23 - Enderman carcass (8 cuts)</h2>

<p>Implemented the <strong>Enderman</strong> carcass with the full 8-cut butchering system. Enderman uses the standard carcass system (not CorpseBlock) with 8 cutting stages, making it the most complex mob ported so far.</p>

<h3>Add</h3>
<ul>
<li><strong>Enderman</strong> — full butchering loop with 8 cuts:
<ul>
<li>Kill → hang from <code>Hook</code> → bleed → cut in sequence for head, then 8 cuts</li>
<li>Each cut drops <strong>raw_enderman_steak</strong> + <strong>animal_fat</strong> (cuts 4-8 also drop <strong>bone</strong>)</li>
<li>Head and head mount display blocks available</li>
<li>No skin, no skeleton</li>
</ul>
</li>
<li><strong>New item:</strong> <code>raw_enderman_steak</code></li>
<li><strong>Voxel shapes</strong> ported 1:1 from original Butchery for all stages (hanging, lying, head, head_mount)</li>
<li><strong>Assets</strong> — blockstates, models, loot tables, textures copied and namespace-remapped</li>
</ul>

<h3>Change</h3>
<ul>
<li>Enderman now drops <code>ender_pearl</code> on death (swept by carcass system)</li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>1 special mob (Enderman)</strong> (8-cut system)</li>
<li><strong>81/79 mobs</strong> ported</li>
</ul>

<p><em>Remaining special mobs: strider, sniffer, turtle (7 cuts), blaze, ghast</em></p>
