<h2>v0.0.0-beta.44 - In-game guide &amp; missing-texture fixes</h2>

<h3>Add</h3>

<ul>
<li><strong>In-game "Butcher's Guide"</strong> via <a href="https://www.curseforge.com/minecraft/mc-mods/vellumli">Vellumli</a> (an <strong>optional</strong> dependency — the book only shows up if Vellumli is installed). Ported from the original mod's Patchouli guide: 4 categories (blocks, guides, items, resources) and 22 entries, with recipes remapped to this mod's IDs and entries for non-ported content (bosses, armour sets, costumes) dropped. Full Spanish translation included. Crafted from a book plus raw meat (<code>#slaughter_hide:raw_meat</code>). The book title and landing text use translation keys.</li>
<li><strong>Dedicated blood drip particle</strong> (<code>slaughter_hide:blood_drip</code>, dark red, gravity-affected) for the bleeding drip, replacing the vanilla dripstone-lava particles it used to borrow.</li>
</ul>

<h3>Fix</h3>

<ul>
<li><strong>Butcher Displays (<code>&lt;wood&gt;_butcher_display</code>) are now a proper two-block-tall structure</strong> (same pattern as the Taxidermy Table): the lower half keeps the tall model and the upper half (<code>&lt;wood&gt;_butcher_display_top</code>, invisible) gives the tile above full solid collision. Placing it fills both tiles; breaking either half removes both and drops one item; it will not place without headroom. Displays placed before this version stay one block until re-placed.</li>
<li><strong>The Blood Puddle rendered as a magenta cube</strong>, both as an item and as a placed block: the item pointed at a flat block model with an animated texture, and the block referenced a texture from the item atlas (not allowed in block models). Item is now <code>item/generated</code>; the block is a thin decal model with its own block-atlas texture.</li>
<li><strong>Blood Bucket / Infected Blood Bucket</strong>: their item definitions used the old loader syntax without the <code>neoforge:item/mask/*</code> masks. Rewritten with an inline <code>neoforge:fluid_container</code> model like the original.</li>
<li><strong>27 blocks rendered as a magenta cube in the inventory</strong> because they were missing their <code>assets/slaughter_hide/items/&lt;id&gt;.json</code> item-definition file (required in MC 26.2): <code>photos</code>, <code>salt_block</code>, <code>spike_trap</code>, <code>sulfur_ore</code>, <code>deepslate_sulfur_ore</code>, the diorite brick block/slab/stairs/wall, <code>dragon_scale_block</code>, <code>plastic_sheet</code> and <code>plastic_sheet_corner</code>, <code>bone_barrel</code>, <code>cod_barrel</code>, <code>salmon_barrel</code>, <code>butcher_statue</code>, <code>floorstanding_sign</code>, <code>cling_film</code>, <code>blood_splatter</code>, raw and cooked sausages (plain and blood), and the four salt formations.</li>
<li><strong>Wishbone and Salt had no texture</strong> — textures restored from the original mod's assets.</li>
<li><strong>The Blood Grate broke in a single hit in survival</strong> — it now has real hardness (<code>strength 3/6</code>) and a metallic sound. Empty-hand right-click also reports the stored blood level (<code>N/3</code>) on the action bar.</li>
</ul>
