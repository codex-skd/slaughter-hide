<h2>v0.0.0-beta.24 - Strider carcass (3 cuts)</h2>

<p>Implemented the <strong>Strider</strong> carcass with a 3-cut butchering system. Strider uses the standard carcass system with hanging/lying poses.</p>

<h3>Add</h3>
<ul>
<li><strong>Strider</strong> — full butchering loop with 3 cuts:
<ul>
<li>Kill → hang from <code>Hook</code> → bleed → cut in sequence for 3 cuts</li>
<li>Each cut drops <strong>raw_strider_meat</strong> (1-2) + <strong>animal_fat</strong> (1-3); cut 3 also drops <strong>bone</strong> (1-2)</li>
<li>No head, head mount, skeleton, or skin</li>
<li>Two blockstates: 0=lying, 1=hanging</li>
</ul>
</li>
<li><strong>New item:</strong> <code>raw_strider_meat</code></li>
<li><strong>Voxel shapes</strong> ported 1:1 from original Butchery for hanging/lying poses</li>
<li><strong>Assets</strong> — blockstates, models, loot tables, textures copied and namespace-remapped</li>
</ul>

<h3>Change</h3>
<ul>
<li>Strider now drops <code>string</code> on death (swept by carcass system)</li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>2 special mobs</strong> (Enderman 8 cuts, Strider 3 cuts)</li>
<li><strong>82/79 mobs</strong> ported</li>
</ul>
