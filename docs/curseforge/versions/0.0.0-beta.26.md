<h2>v0.0.0-beta.26 - Turtle carcass (7 cuts)</h2>

<p>Implemented the <strong>Turtle</strong> carcass with a 7-cut butchering system. Turtle uses the standard carcass system with 17 drained stages (0=lying, 1=hanging, 2-17=drained cuts).</p>

<h3>Add</h3>
<ul>
<li><strong>Turtle</strong> — full butchering loop with 7 cuts + shell fragments + legs:
<ul>
<li>Kill → hang from <code>Hook</code> → bleed → cut in sequence for shell fragments (cut 1), head, head mount, then 7 cuts</li>
<li>Shell fragment cut drops <strong>turtle_shell_fragment</strong></li>
<li>Head and head mount display blocks available</li>
<li>Meat cuts 1-6 drop <strong>raw_turtle_meat</strong> (1-2) + <strong>animal_fat</strong></li>
<li>Cut 7 drops <strong>raw_turtle_meat</strong> (1-2) + <strong>animal_fat</strong> + <strong>turtle_shell_fragment</strong> + <strong>bone</strong> (1-3)</li>
<li>Leg drop (separate block) drops <strong>raw_turtle_meat</strong> (1-4) + <strong>animal_fat</strong> (1-4) + <strong>bone</strong> (1-3)</li>
<li>No skeleton</li>
</ul>
</li>
<li><strong>New items:</strong> <code>raw_turtle_meat</code>, <code>turtle_shell_fragment</code></li>
<li><strong>Voxel shapes</strong> ported 1:1 from original Butchery for all stages (hanging, lying, head, head_mount, 17 drained stages)</li>
<li><strong>Assets</strong> — blockstates, models, loot tables, textures copied and namespace-remapped</li>
</ul>

<h3>Change</h3>
<ul>
<li>Turtle now drops <code>scute</code> (mapped to seagrass) on death (swept by carcass system)</li>
<li>Fixed duplicate magma_cube registration in ModBlocks</li>
</ul>
