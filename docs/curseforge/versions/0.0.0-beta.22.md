<h2>v0.0.0-beta.22 - CorpseBlock system for 10 humanoid mobs</h2>

<p>Implemented the <strong>CorpseBlock organ-harvesting system</strong> for all humanoid mobs that require it (zombie, skeleton, drowned, husk, vindicator, evoker, witch, piglin, piglin_brute, ravager). These mobs use a 9-slot container-based block entity instead of the standard 5-stage carcass system.</p>

<h3>Add</h3>
<ul>
<li><strong>10 new CorpseBlock mobs</strong> with full butchering loops: zombie, skeleton, drowned, husk, vindicator, evoker, witch, piglin, piglin_brute, ravager</li>
<li><strong>CorpseBlockEntity</strong> — 9-slot container block entity for storing organs during butchering</li>
<li><strong>CorpseBlock</strong> — generic block with hanging/lying poses using voxel shapes from original Butchery</li>
<li><strong>Voxel shapes</strong> ported 1:1 from original Butchery for all 10 mobs (hanging, lying, head, head_mount, corpse stages)</li>
<li><strong>Loot tables</strong> for all cutting stages (head, skin, 3 cuts) with organ drops</li>
<li><strong>Assets</strong> — blockstates, models, textures copied and namespace-remapped from butchery → slaughter_hide</li>
</ul>

<h3>Change</h3>
<ul>
<li>Fixed <code>CorpseBlockEntity</code> for NeoForge 26.2 (corrected <code>createMenu</code> signatures, <code>loadAdditional</code>/<code>saveAdditional</code> with <code>ValueInput</code>/<code>ValueOutput</code>)</li>
<li>Added <code>corpseShapes()</code> method to <code>CarcassDefinition</code> record</li>
<li>Registered CorpseBlock families in <code>ModBlocks</code> and items in <code>ModItems</code></li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>80/79 mobs</strong> (ravager added as bonus)</li>
</ul>
