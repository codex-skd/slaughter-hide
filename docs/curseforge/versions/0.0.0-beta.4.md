<h2>v0.0.0-beta.4 - Hook required to hang a carcass</h2>

<p>Restricts carcass placement to match the original mod, per playtest feedback.</p>

<h3>Change</h3>
<ul>
<li><strong>Carcasses can no longer be placed anywhere</strong>: you now need a <code>Hook</code> block. Right-click a placed Hook while holding a <code>Cow Carcass</code> (or <code>Drained Cow Carcass</code>) item to hang it directly below.</li>
</ul>

<h3>Known issues</h3>
<ul>
<li>The original's <code>Rope</code> block (an alternative hanging point that needs "spooling" with repeated right-clicks) is not implemented yet — its exact original behavior could not be reliably reconstructed from decompiled bytecode. Only <code>Hook</code> works for now.</li>
</ul>
