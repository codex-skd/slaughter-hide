<h2>v0.0.0-beta.28 - Fix static init crash (ExceptionInInitializerError)</h2>

<p>Hotfix for the client crash on startup caused by a circular static initialization dependency.</p>

<h3>Fix</h3>
<ul>
<li>Removed unused <code>import com.skd.slaughterhide.init.ModItems;</code> from <code>Carcasses.java</code> which was creating a circular static initialization dependency between <code>ModItems</code> (referencing <code>Carcasses</code> constants) and <code>Carcasses</code> (importing <code>ModItems</code>), causing <code>ExceptionInInitializerError</code> during mod loading.</li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>4 special mobs</strong> (Enderman 8 cuts, Strider 3 cuts, Sniffer 3 cuts + fur + head, Turtle 7 cuts)</li>
<li><strong>84/79 mobs</strong> ported</li>
</ul>

<p><em>Same features as beta.27, but with the startup crash fixed. Users experiencing crashes with beta.27 should update to this version.</em></p>
