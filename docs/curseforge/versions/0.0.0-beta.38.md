<h2>v0.0.0-beta.38 - Startup crash hotfix</h2>

<p>beta.37 crashed on startup during mod registration. This release only fixes that crash &mdash; all of beta.37's content (the 4 machines, the blood system, the completed kill-to-cut loop, the cleanup) is unchanged and now actually loads.</p>

<h3>Fix</h3>

<ul>
<li><strong>Fixed the beta.37 boot crash</strong> (<code>NullPointerException: Item id not set</code>). The two blood bucket items were built with an empty item-properties object instead of the one the registry hands them, and Minecraft 26.2's <code>BucketItem</code> constructor rejects that. Nothing else in beta.37 was reachable because the crash aborted registration before models and textures were loaded.</li>
</ul>

<blockquote>Still a beta &mdash; the machine GUIs and the blood fluid rendering have not been smoke-tested in a running client yet.</blockquote>
