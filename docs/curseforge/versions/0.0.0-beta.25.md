<h2>v0.0.0-beta.25 - Sniffer carcass (3 cuts + fur + head)</h2>

<p>Implemented the <strong>Sniffer</strong> carcass with a 3-cut butchering system plus fur and head. Sniffer uses the standard carcass system with a cube-shaped model.</p>

<h3>Add</h3>
<ul>
<li><strong>Sniffer</strong> — full butchering loop with 3 cuts + fur + head:
<ul>
<li>Kill → hang from <code>Hook</code> → bleed → cut in sequence for fur, head, then 3 cuts</li>
<li>Fur cut drops <strong>animal_fat</strong> (1-8)</li>
<li>Head cut drops <strong>sniffer_head</strong></li>
<li>Each meat cut drops <strong>raw_sniffer_steak</strong> (1-3) + <strong>animal_fat</strong> (1-8); cut 3 also drops <strong>bone</strong></li>
<li>Head display block available</li>
<li>No head mount, skeleton, or skin</li>
</ul>
</li>
<li><strong>New items:</strong> <code>raw_sniffer_steak</code>, <code>sniffer_fur</code> (internal)</li>
<li><strong>Voxel shapes</strong> — cube for carcass, head uses same model</li>
<li><strong>Assets</strong> — blockstates, models, loot tables, textures copied and namespace-remapped</li>
</ul>

<h3>Change</h3>
<ul>
<li>Sniffer now drops <code>torchflower_seeds</code> on death (swept by carcass system)</li>
<li>Fixed duplicate magma_cube registration in ModBlocks</li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>3 special mobs</strong> (Enderman 8 cuts, Strider 3 cuts, Sniffer 3 cuts + fur + head)</li>
<li><strong>83/79 mobs</strong> ported</li>
</ul>
