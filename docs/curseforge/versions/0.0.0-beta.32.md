<h2>v0.0.0-beta.32 - 7 new blocks + a real loot-table bugfix</h2>

<p>Adds 7 more blocks from the original Butchery catalog and fixes a bug that likely made most humanoid and "special" mobs drop nothing when cut up.</p>

<h3>Add</h3>
<ul>
<li><code>basin</code> — slowly collects salt near the salt formation blocks.</li>
<li><code>brain</code> — attracts nearby zombies.</li>
<li><code>cash_register_block</code> — drawer opens/closes on right-click.</li>
<li><code>skin_rack</code> — hangs a mob skin for display.</li>
<li><code>wooden_spit_rotisserie</code> — cooks a pig carcass over a campfire (raw &gt; cooked &gt; burnt).</li>
<li><code>jar</code> — displays a single stored item.</li>
<li><code>metal_tray</code> — decorative.</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Major</strong>: most humanoid corpse mobs (zombie, drowned, husk, piglin, piglin brute, skeleton, vindicator, witch, evoker) and the "special" mobs (enderman, endermite, sniffer, strider, turtle) had their cutting-stage loot tables sitting in the wrong data folder and were very likely dropping nothing at all when butchered, silently. Moved to the correct location — their drops should now actually work.</li>
<li>Enderman/Turtle were configured for 8/7 cuts but the cutting handler only ever supports 3 — capped to match reality instead of over-promising content that was never reachable.</li>
<li>Ravager and Pufferfish's fresh-carcass block had no matching model, showing as a missing-texture placeholder — fixed.</li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>4 special mobs</strong> (Enderman, Strider, Sniffer, Turtle)</li>
<li><strong>84/79 mobs</strong> ported</li>
</ul>

<p><em>Still missing: the 4 GUI-driven workstations (Freezer, Meat Grinder, Pestle &amp; Mortar, Taxidermy Table), visible blood, the Iron Golem set, and real tool-tier textures (still placeholders).</em></p>
