<h2>v0.0.0-beta.43 - Solid taxidermy table</h2>

<h3>Fix</h3>

<ul>
<li><strong>The Taxidermy Table is now a proper two-block structure</strong>, so its wide half is solid instead of walk-through. Place it and it fills two tiles; break either half and both go, dropping one table; right-clicking either half opens the menu. Tables placed before this version keep a walk-through half until re-placed.</li>
