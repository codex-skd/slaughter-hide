<h2>v0.0.0-beta.29 - Fix duplicate item registration crash</h2>

<p>Hotfix for the <code>ExceptionInInitializerError</code> caused by duplicate item registrations in <code>ModItems</code> static initializer.</p>

<h3>Fix</h3>
<ul>
<li>Fixed duplicate item registrations for goat meat cuts (were using same registry names as sheep):
<ul>
<li><code>raw_leg_of_lamb</code> → <code>raw_leg_of_lamb_goat</code></li>
<li><code>raw_lamb_shoulder</code> → <code>raw_lamb_shoulder_goat</code></li>
<li><code>raw_lamb_rib</code> → <code>raw_lamb_rib_goat</code></li>
<li><code>raw_lamb_sirloin</code> → <code>raw_lamb_sirloin_goat</code></li>
<li><code>raw_lamb_loin</code> → <code>raw_lamb_loin_goat</code></li>
<li><code>hoof</code> → <code>hoof_goat</code></li>
</ul>
</li>
<li>All goat meat items now have unique registry names</li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>4 special mobs</strong> (Enderman 8 cuts, Strider 3 cuts, Sniffer 3 cuts + fur + head, Turtle 7 cuts)</li>
<li><strong>84/79 mobs</strong> ported</li>
</ul>
