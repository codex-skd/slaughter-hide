<h2>v0.0.0-beta.39 - Blood polish &amp; tool tiers</h2>

<p>Small follow-up to beta.38 fixing the things that stood out once the blood system was actually in-game.</p>

<h3>Fix</h3>

<ul>
<li><strong>All tool tiers work now.</strong> Only the iron cleaver and iron skinning knife were wired to the butchering tags &mdash; copper, gold, diamond and netherite were craftable but did nothing. All four tiers are now recognised for bleeding and cutting.</li>
<li><strong>Blood Grate</strong> no longer looks like a solid cube of blood &mdash; it uses its real metal-grate model. (The 0&ndash;3 fill level is still only functional, not shown on the model yet.)</li>
<li><strong>Blood Puddle</strong> is now a thin flat layer you can walk through, instead of a solid red block.</li>
<li><strong>Bleeding drips continuously.</strong> A bleeding carcass now spits a small burst of blood every couple of seconds for the whole drain, filling a grate underneath it over a few pulses or leaving a puddle &mdash; instead of a single one-off effect you could miss.</li>
</ul>

<blockquote>How to butcher: kill an animal &rarr; place a <strong>Hook</strong> on a wall with air below it &rarr; right-click the Hook with the dropped carcass item &rarr; right-click the hanging carcass with a <strong>Cleaver</strong> to bleed it (set <code>instant_bleeding = true</code> in the config to skip the 45s wait) &rarr; on the drained carcass: cleaver for the head, skinning knife for the hide, then cleaver three more times for the cuts.</blockquote>
