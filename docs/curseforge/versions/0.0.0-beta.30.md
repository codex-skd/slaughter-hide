<h2>v0.0.0-beta.30 - Fix CorpseBlock registration crash</h2>

<p>Fixed a critical crash during mod loading where CorpseBlock entity types were being registered without valid blocks.</p>

<h3>Fix</h3>
<ul>
<li>Added missing <code>registerCorpseFamily()</code> calls for all 10 humanoid CorpseBlock mobs (Zombie, Skeleton, Drowned, Husk, Vindicator, Evoker, Witch, Piglin, Piglin Brute, Ravager) in <code>ModBlocks</code> static initializer</li>
<li>Fixes <code>Block entity type instantiated without valid blocks</code> crash during mod loading</li>
</ul>

<h3>Total mobs ported</h3>
<ul>
<li><strong>70 generic carcass mobs</strong> (standard 5-stage system)</li>
<li><strong>10 CorpseBlock mobs</strong> (organ-harvesting system)</li>
<li><strong>4 special mobs</strong> (Enderman 8 cuts, Strider 3 cuts, Sniffer 3 cuts + fur + head, Turtle 7 cuts)</li>
<li><strong>84/79 mobs</strong> ported</li>
</ul>

<p><em>Same features as beta.29, but with the CorpseBlock registration crash fixed. Users experiencing crashes with beta.29 should update to this version.</em></p>
