<h2>v0.0.0-beta.3 - Playtest fixes</h2>

<p>Fixes for issues found while playtesting v0.0.0-beta.2.</p>

<h3>Fix</h3>
<ul>
<li><strong>Carcass placement</strong>: killing a cow now drops a placeable <code>Cow Carcass</code> item instead of automatically hanging the carcass block at the death spot. Place it yourself, then start the bleed/cut sequence.</li>
<li><strong>Cow Head Mount texture</strong>: the mounted head trophy block now renders correctly. The previous version's model mixed two different UV coordinate scales on one face, a bug inherited from the original Butchery mod's asset that NeoForge 26.2's stricter model validation exposed.</li>
</ul>

<h3>Add</h3>
<ul>
<li>Spanish (<code>es_es</code>) translation.</li>
</ul>
