<h2>v0.0.0-beta.5 - Pig added</h2>

<p>Second mob added to the butchering system.</p>

<h3>Add</h3>
<ul>
<li><strong>Pig</strong>: full butchering loop, same as the cow — kill, hang from a <code>Hook</code>, bleed, cut in sequence for head, skin, and five meat cuts (shoulder, loin, leg, belly, ham).</li>
</ul>

<h3>Fix</h3>
<ul>
<li>Breaking a mid-cut drained carcass (instead of finishing the cutting sequence) now drops the correct meat scrap for that mob, instead of always dropping beef.</li>
</ul>
