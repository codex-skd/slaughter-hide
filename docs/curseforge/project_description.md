<h2>✨ Overview</h2>

<p>Slaughter & Hide is a Minecraft 26.2 (NeoForge) mod, currently in early scaffold stage (<code>0.0.0-beta.1</code>). No gameplay features are implemented yet — this description will be expanded as the mod's mechanics are ported and built.</p>

<blockquote>This mod is a port of <a href="https://www.curseforge.com/minecraft/mc-mods/butchery"><strong>Butchery</strong></a> by <em>Jmods</em>, ported from NeoForge 26.1.2 to NeoForge 26.2, with all identifiers renamed to this project's convention. Used with explicit permission from the original author.</blockquote>
